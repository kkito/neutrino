# egress（出网代理 一期 HTTP） Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** agent 本地 HTTP 正向代理经 WSS 让 server 拨公网，出口 IP = server。

**Architecture:** agent 新增 `src/egress.rs` 做本地 HTTP 代理监听（CONNECT + 绝对 URI），复用 `Ctx/out` 发 `ClientMsg::Open{kind:"egress"}` 建流，复用 Binary stream 泵；server 在 `ws_loop` 处理该 Open，直连 `TcpStream::connect`（30s 超时）后接现有 outbox/incoming 泵；agent WebUI 加出网代理页。

**Tech Stack:** Rust, tokio TcpListener, axum（agent_web）, tokio-tungstenite Message, 现有 proto 帧。

## Global Constraints

- `make build` 零 warning（RUSTFLAGS="-D warnings"）才算过。

```rust
//! Agent-local HTTP forward proxy request parsing (pure, no IO).
pub enum ProxyTarget { Connect{host:String,port:u16}, Forward{host:String,port:u16,head:Vec<u8>} }

fn split_host_port(h: &str) -> (String, u16) {
    match h.rsplit_once(':') {
        Some((hh, p)) => match p.parse::<u16>() { Ok(n)=> (hh.trim().to_string(), n), Err(_)=> (h.to_string(), 80) },
        None => (h.to_string(), 80),
    }
}

pub fn parse_proxy_request(buf: &[u8]) -> Option<(ProxyTarget, usize)> {
    let end = buf.windows(4).position(|w| w==b"\r\n\r\n")? + 4;
    let head = std::str::from_utf8(&buf[..end]).ok()?;
    let mut lines = head.lines();
    let req = lines.next()?;
    let mut parts = req.split_whitespace();
    let (m, target) = (parts.next()?, parts.next()?);
    if m.eq_ignore_ascii_case("CONNECT") {
        let (h,p) = split_host_port(target);
        Some((ProxyTarget::Connect{host:h,port:p}, end))
    } else {
        // 普通 HTTP：只接受绝对 URI
        let after = target.split("://").nth(1)?;
        let hostport = after.split('/').next()?;
        let (h,p) = split_host_port(hostport);
        Some((ProxyTarget::Forward{host:h,port:p,head:buf[..end].to_vec()}, end))
    }
}
```

proto.rs 注释：`kind: String, // "http" | "tcp" (agent-initiated; reserved)` → `// "http" | "tcp" | "egress"(agent-initiated)`。main.rs 加 `pub mod egress;`。

简化：`serve_egress(bind, out_holder: Arc<RwLock<Option<mpsc::UnboundedSender<Message>>>>, status)`；`session()` 建 `out_tx` 后写入 holder，结束置 None（fail-fast：None 时直接回 `HTTP/1.1 502 Bad Gateway` 并关连接）。

egress.rs `serve_egress` 每连接：读到 `\r\n\r\n` → `parse_proxy_request` → 失败回 400；成功则 sid=rand u32（奇数，避开 server 偶数）→ 发 `ClientMsg::Open{kind:"egress"}`（需 out 通道 + 注册本地 `streams/pending`？agent 现有 streams 表在 Ctx 内。为最小实现：egress 连接自建 `(dtx,drx)` pair 存在全局 `EgressStreams: Arc<RwLock<HashMap<u32, Sender>>>`，`session` 的 Binary 分发先查 Ctx.streams 再查 EgressStreams）。
CONNECT 成功等 server 首包回数据即回 `HTTP/1.1 200 Connection Established\r\n\r\n`；server Close（reason 含 denied/dial）则回 502 并关连接。Forward 则 Open 后把原 head 发 Binary，server 回包直接透传。双向泵用 `select!` 任一 EOF 发 Close。

为控制 scope：本 task 先实现 CONNECT + Forward 建流与裸泵（不做 http_response_pump 那套边界解析——egress 对端是公网任意服务，按 tcp 裸流处理）。
